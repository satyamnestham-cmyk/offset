Offset Points – QGIS Plugin

AutoCAD-style Survey Offset and Prolong Tool for QGIS.

Features

- Positive Offset = Right Side.
- Negative Offset = Left Side.
- Positive Cutting Distance = Forward.
- Negative Cutting Distance = Backward.
- Extend or Prolong the baseline.
- Continuous point creation.

Installation

1. Open QGIS.
2. Go to Plugins → Manage and Install Plugins.
3. Select Install from ZIP.
4. Select Offset_Points.zip.
5. Click Install Plugin.
