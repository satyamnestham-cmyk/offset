QGIS AutoCAD Survey OFFSET and PROLONG

Features

- AutoCAD-style OFFSET command for QGIS.
- Select First Point and Second Point to define the baseline.
- Enter Cutting Distance.
- Positive Offset = Right Side.
- Negative Offset = Left Side.
- Negative Cutting Distance = Move Backward.
- Extend or Prolong the line using Prolong Distance.
- Continuous point creation in the same command.

How to Use

1. Open QGIS.
2. Load your QGIS project.
3. Activate the OFFSET plugin.
4. Select First Point.
5. Select Second Point.
6. Enter Cutting Distance.
7. Enter Offset Distance.
8. Enter Prolong Distance.
9. Continue creating points without restarting the command.

Installation

1. Download offset.zip.
2. Open QGIS.
3. Go to Plugins → Manage and Install Plugins.
4. Select Install from ZIP.
5. Choose offset.zip and install.

Requirements

- QGIS 3.16 or later.
- Python 3.
